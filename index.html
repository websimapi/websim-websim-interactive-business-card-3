WebSim Interactive Business Card - User Guide

Getting Started

Welcome to the WebSim Interactive Business Card! This application allows you to create, customize, and export professional business cards with interactive features.

Basic Interactions

  • Hover Effects: Move your mouse over the card to see animations and particle effects
  • Right-Click Menu: Right-click anywhere on the card to open the context menu with options
  • Logo Animation: Hover over the WebSim logo to see the letters wiggle

Context Menu Options

  • Edit Card: Makes all text fields editable - click on text to modify it
  • Embed User Profile: Automatically fills in your WebSim profile information and avatar
  • Reset Card: Restores the card to its default WebSim branding
  • Print Card: Opens the print dialog for physical printing
  • Convert to STL: Exports a 3D printable STL file with embossed text and engraved QR code

Editing Features

  • When in edit mode, click on any text to modify it
  • Changes are saved automatically as you type
  • Click outside the card or use the reset option to exit edit mode

QR Code

The QR code automatically updates based on the website URL shown on the card. When you embed your user profile, it will link to your WebSim profile page.

3D STL Export

The STL export creates a 3D model suitable for 3D printing with:

  • Embossed text that extends from the card surface
  • Engraved QR code with proper black/white depth variations
  • Standard business card dimensions (3.5" x 2")

Printing

Use the print option for high-quality physical cards. The print version removes animations and optimizes colors for paper output.

Tips

  • Embed your profile before exporting to STL for personalized cards
  • Keep text concise for best 3D printing results
  • The particle effects only appear when not printing
